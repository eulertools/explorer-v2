# explorer-v2

Thin Next.js + Material UI + Storybook template used as a starting point for Euler Tools explorer/SaaS UI. Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/explorer-v2-archive`.

## What was built (EN)

Next.js, TypeScript, MUI, Storybook, Jest. Sample subscription hero/list components, empty GTM id, Terraform under `.aws/` for a generic `nextjs-fargate-demo` (account id from `aws_caller_identity`, state bucket uses `XXXXX` placeholder). No recorded product contract deployments.

## Qué se construyó (ES)

Plantilla Next.js/MUI para el explorer. Sin deployments de contratos.
